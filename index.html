      DeepSeek-V3 Technical Report

      A 671B-parameter mixture-of-experts model trained for 2.788M H800 GPU hours. The work rests on four moves: balancing experts without a loss penalty, predicting two tokens ahead, training in FP8, and overlapping communication with compute.

      Interactive · simulation

      Router playground: auxiliary-loss-free load balancing

      0training steps
      –busiest expert ÷ average
      –experts under half load

      What to notice. Without balancing, a few popular experts take most tokens and the rest barely train. With bias adjustment, each expert gets a bias that is nudged down when it is overloaded and up when it is idle. The bias only changes which experts are picked. Gate weights still use the raw affinity, so no extra loss term pulls against language modelling. Scaled down here to 16 experts, top-2. V3 uses 256 routed experts plus 1 shared, top-8, and keeps a tiny sequence-level balance loss (α = 0.0001) as a safety net.

      Interactive · calculator

      KV cache at inference

      What to notice. MLA caches one 512-dim latent plus a 64-dim RoPE key per token per layer (576 numbers) instead of full keys and values for 128 heads (32,768 numbers). The MHA and GQA rows are hypothetical: the same 61-layer model with standard attention. BF16, one sequence.

      Interactive · stepper

      Multi-token prediction

      context seen main head target (t+1) MTP target (t+2)

      What to notice. Every position now yields two training signals. The MTP module takes the main model's hidden state plus the embedding of the next token, so the causal chain is kept. At inference it can be dropped, or used for speculative decoding: the paper reports 85–90% acceptance of the second token.

      What to notice. The middle span is moved to the end, so ordinary left-to-right training teaches the model to fill gaps given what comes after. It is applied to about 10% of documents, which keeps next-token ability intact.       What to notice. Each row is a tile of activations; one value in the top row is an outlier. FP8 (E4M3) tops out at 448, so a single scale sized for the outlier pushes every small value toward zero. Scaling each tile separately confines the damage to the outlier's own tile. V3 uses 1×128 tiles for activations and 128×128 blocks for weights, and accumulates in higher precision. Rows of 32 are shown here for space.
